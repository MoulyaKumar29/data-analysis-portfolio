\# Healthcare Data Analysis



\## Project Overview

This project uses Python to analyze a synthetic healthcare dataset containing 20 patient records. It explores patient demographics, medical conditions, blood pressure, glucose levels, treatments, and recorded recovery outcomes.



\## Objectives

\- Explore patient demographics and medical conditions.

\- Calculate descriptive statistics.

\- Analyze blood pressure and glucose levels.

\- Compare recorded outcomes across treatment groups.

\- Perform basic statistical analysis.

\- Create visualizations to explore patterns in the data.



\## Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- SciPy

\- Jupyter Notebook



\## Dataset

The dataset contains 20 synthetic patient records with information about age, gender, medical condition, blood pressure, glucose level, treatment, and recovery status.



\## Analysis and Visualizations

\- Medical condition distribution

\- Gender distribution

\- Age distribution

\- Average blood pressure by medical condition

\- Average glucose level by medical condition

\- Recovery status by treatment

\- Age-group distribution

\- Correlation heatmap

\- Blood pressure versus glucose scatter plot

\- Statistical comparison of glucose levels between recovery groups



\## Key Findings

\- Total patient records: 20

\- Average age: 47.25 years

\- Average blood pressure: 141.60

\- Average glucose level: 123.60

\- The sample contains equal numbers of male and female patients.

\- Diabetes is the most frequent medical condition in the sample.



\## Limitations

The dataset is synthetic and intended only for educational purposes. The findings do not represent real patients and cannot establish medical relationships or treatment effectiveness.



\## How to Run

1\. Install Python and the required libraries.

2\. Open `Week2\_Healthcare\_Data\_Analysis.ipynb` in Jupyter Notebook.

3\. Run the notebook cells in order.

4\. Review the analysis outputs and visualizations.



\## Conclusion

This project demonstrates how Python can be used to explore healthcare data, calculate statistics, visualize patterns, and perform a basic statistical test.
