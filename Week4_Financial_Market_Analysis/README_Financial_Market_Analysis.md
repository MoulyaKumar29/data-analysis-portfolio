\# Financial Market Analysis



\## Project Overview

This project uses Python to analyze a synthetic stock market dataset containing 15 days of stock prices and trading volumes.



\## Objectives

\- Analyze opening, highest, lowest, and closing prices.

\- Calculate daily percentage returns.

\- Measure daily return volatility.

\- Calculate cumulative price changes.

\- Examine trading volume.

\- Identify the best and worst days by daily return.

\- Create visualizations to explore price movements.

\- Check the dataset for missing values, duplicates, and inconsistent prices.



\## Technologies Used

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Jupyter Notebook



\## Dataset

The dataset includes:

\- Date

\- Open

\- High

\- Low

\- Close

\- Volume

\- Daily\_Return

\- Cumulative\_Return



\## Analysis and Visualizations

\- Closing price trend

\- Daily returns chart

\- Opening, high, low, and closing price comparison

\- Trading volume chart

\- Closing price distribution

\- Correlation heatmap

\- Best and worst trading day analysis

\- Daily return volatility



\## Limitations

The dataset is synthetic and intended for educational purposes. It does not represent actual market prices and should not be used to make investment decisions.



\## How to Run

1\. Install Python and the required libraries.

2\. Open `Week4\_Financial\_Market\_Analysis.ipynb` in Jupyter Notebook.

3\. Run the notebook cells in order.

4\. Review the analysis results and visualizations.



\## Conclusion

This project demonstrates how Python can be used to analyze stock price movements, calculate returns, examine volatility, and visualize financial data.
