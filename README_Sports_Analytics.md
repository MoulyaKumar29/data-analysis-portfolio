**# Sports Analytics**



**## Project Overview**

**This project uses Python to analyze a synthetic cricket dataset containing 15 players. It explores player performance through runs, wickets, matches, and strike rates.**



**## Objectives**

**- Analyze player performance.**

**- Identify top run scorers and wicket takers.**

**- Compare runs and strike rates.**

**- Calculate runs per match.**

**- Create visualizations to understand performance.**

**- Check data quality and export the dataset.**



**## Technologies Used**

**- Python**

**- Pandas**

**- NumPy**

**- Matplotlib**

**- Seaborn**

**- Jupyter Notebook**



**## Dataset**

**The dataset contains 15 player records with the following columns:**

**- Player**

**- Team**

**- Matches**

**- Runs**

**- Wickets**

**- Strike\_Rate**

**- Runs\_Per\_Match**



**## Analysis Performed**

**- Dataset inspection and descriptive statistics**

**- Top five players by runs**

**- Top five players by wickets**

**- Average runs and wickets**

**- Runs per match**

**- Runs versus strike rate**

**- Player strike-rate ranking**

**- Team performance summary**

**- Runs and wickets comparison**

**- Missing values and duplicate checks**



**## Limitations**

**The dataset is synthetic and intended for learning and demonstration. It does not represent verified real-world player statistics.**



**## How to Run**

**1. Install Python and the required libraries.**

**2. Open `Week3\_Sports\_Analytics.ipynb` in Jupyter Notebook.**

**3. Run the cells in order.**

**4. Review the analysis results and charts.**



**## Conclusion**

**This project demonstrates how Python can be used to analyze sports data, calculate performance statistics, create visualizations, and identify patterns in player performance.**
