# Week 5: E-commerce Analytics

## Project Overview
This project analyzes a synthetic e-commerce dataset using Python to understand product performance, customer behavior, regional sales, and revenue distribution.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Description
The dataset contains 20 sample order records with the following columns:
- Order_ID
- Product
- Category
- Quantity
- Unit_Price
- Region
- Customer_Type
- Revenue

Revenue is calculated by multiplying quantity by unit price.

## Analysis Performed
1. Dataset inspection and descriptive statistics.
2. Total revenue and average order value calculations.
3. Revenue analysis by product and category.
4. Regional revenue comparison.
5. New versus returning customer analysis.
6. Highest- and lowest-revenue order identification.
7. Product quantity and average price analysis.
8. Product revenue contribution percentages.
9. Missing values and duplicate record checks.
10. Correlation analysis of numerical variables.

## Visualizations
- Product revenue bar chart
- Category revenue bar chart
- Regional revenue bar chart
- Customer type revenue chart
- Revenue distribution histogram
- Customer order count chart
- Category revenue pie chart
- Units sold bar chart
- Quantity versus revenue scatter plot
- Unit price versus quantity scatter plot
- Numerical correlation heatmap

## Output Files
- `Week5_Ecommerce_Analytics.ipynb`
- `ecommerce_data.csv`
- `README_Ecommerce_Analytics.md`

## Limitations
The dataset is synthetic and contains only 20 sample orders. The results demonstrate data analysis techniques and should not be interpreted as actual business performance.

## Conclusion
This project demonstrates how Python can be used to calculate revenue, compare product and category performance, analyze customer orders, identify data quality issues, and visualize e-commerce trends.
